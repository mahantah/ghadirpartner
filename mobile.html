اسکن بارکد سریال دستگاه

برای بارکدهای خطی روی جعبه مثل نمونه I90، دوربین را افقی نگه دارید و خود بارکد را کامل داخل تصویر قرار دهید. موتور جدید Code 128، Code 39، Code 93، EAN، ITF و Codabar را می‌خواند.
بارکد خطی را در مرکز کادر دوربین قرار دهید
کنترل سریال تکراری و الگوی هر مدل توسط خود سامانه انجام می‌شود. اگر سریال خارج از الگو باشد یا قبلاً ثبت شده باشد، عملیات رد می‌شود.
