# GhadirPay

نسخه مبنا: V5.2.32.20-BULK-WAREHOUSE-LABELS

این مخزن فقط کد برنامه را نگهداری می‌کند. اطلاعات زنده مشتریان، سفارش‌ها، سریال‌ها و تنظیمات حساس هاست نباید داخل GitHub Commit شوند.

## فایل‌های محلی سرور که در Git نگهداری نمی‌شوند
- `storage/ghadir_data.json`
- `config.php`
- `partners/config.php`
- لاگ‌ها و فایل‌های بکاپ

برای نصب اولیه، `config.example.php` را به `config.php` و `partners/config.example.php` را به `partners/config.php` کپی کنید و مقادیر لازم را تنظیم کنید.

## دسترسی قیمت مشتری
از اتوماسیون وب → مشتریان → ویرایش، برای هر مشتری مشخص کنید کدام نوع قیمت را در پرتال ببیند: عامل فروش، ثبت در پنل، سریال آزاد. مقدار در `visible_price_groups` ذخیره می‌شود و کاتالوگ مشتری فقط همان ستون‌ها را برمی‌گرداند.
