# بسته انتقال صفحه ورود قدیر پارتنر (آماده بررسی — بدون انتشار اصلی)

تاریخ تهیه: ۱۴۰۵/۰۷/۳۰ (۲۲ اکتبر ۲۰۲۶)

این شاخه فقط **منابع طراحی** را آماده می‌کند. فایل `app.html` اصلی، PHP، config، دیتابیس، سفارش‌ها و انبار **اصلاً تغییر نکرده‌اند**. شاخه `main` هنوز مرجع قطعی فایل‌های فعال روی هاست نیست؛ بنابراین این بسته نباید با جایگزینی کامل `app.html` یا Merge مستقیم به سایت اصلی منتقل شود.

## محتویات
- `login-fragment.html`: HTML فقط بخش `#login` مطابق نسخه تست، اما **بدون برچسب «نسخه آزمایشی»**
- `assets/staging-login-fullscreen-v2.css`: فایل کامل طراحی فرم (شیشه‌ای، RTL، Uiverse-inspired، آیکون‌های SVG)
- `assets/staging-login-fullscreen-v2.js`: نمایش و مخفی‌کردن رمز بدون تغییر منطق ورود
- `assets/staging-lobby-login-v5.webp`: تصویر تأییدشده دفتر و لوگوی دیوار

## بررسی ضروری قبل از انتقال به سایت اصلی
1. یک نسخه کامل و زمان‌دار از **فایل فعال `/home/ghadirpartner/public_html/app.html`** و فایل‌های وابسته بردارید؛ همچنین در صورت امکان نسخه SQL آماده بازیابی نگه دارید. **بازیابی کل دیتابیس ممنوع است** مگر ضرورت قطعی.
2. فایل HTML فعلی *همان سایت اصلی* را با GitHub مقایسه کنید: GitHub `main` و `staging` متفاوت‌اند. **هیچ‌کدام را کورکورانه جایگزین فایل فعال نکنید.**
3. تطبیق `#login`، توابع ورود / خروج و بازیابی `toggleStaffReset`، `requestStaffOtp`، `confirmStaffReset` و شناسه‌های `loginbtn`، `lu`، `lp` را با کد فعال انجام دهید. اگر سرویس پیامکی در سایت اصلی فعال نیست، UI بازیابی باید مطابق سرویس موجود تطبیق یابد.
4. در برنامه‌ی انتقال تأییدشده فقط چهار فایل فوق را به مسیرهای مناسب اضافه کنید؛ در `app.html` **فقط بخش `#login`** و ارجاعات CSS/JS را با بازبینی تطبیقی تغییر دهید. مسیرهای API، `config.php`، `.htaccess` و سایر کدهای سامانه را تغییر ندهید.
5. قبل از انتشار نهایی، در محیط آزمایشی ورود مدیر، خروج، رفرش نشست، خطای رمز اشتباه، نمایش/مخفی‌سازی رمز، موبایل و بازیابی را بررسی کنید.
6. انتشار اصلی تنها بعد از تأیید صریح کارفرما و اطمینان از سازگاری فایل زنده انجام شود. امکان Rollback فوری با برگرداندن `app.html` قبلی فراهم باشد.

## نکات وابستگی
- در CSS مسیر فونت `/assets/fonts/IRANSansWeb.woff2` آمده است؛ فقط در صورت داشتن فایل دارای مجوز به‌درستی نمایش داده می‌شود.
- SVGهای کوچک داخل HTML هستند؛ به CDN یا فونت آیکون خارجی وابسته نیستند.
- این بسته **نسخه آماده انتقال برای بازبینی** است، نه مجوز انتشار و نه تضمین سازگاری با دیتابیس یا کد فعال سایت اصلی.
