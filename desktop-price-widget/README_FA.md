# ویجت قیمت زنده قدیر پارتنر

این برنامه یک پنجره سبک ویندوزی برای نمایش قیمت و موجودی زنده دستگاه‌ها از پرتال قدیر پارتنر است.

## منبع داده

برنامه از API رسمی همان پرتال استفاده می‌کند:

- ورود: `/partners/api/login`
- احراز نشست: `/partners/api/me`
- قیمت و موجودی: `/partners/api/catalog`

هیچ صفحه‌ای اسکرپ نمی‌شود. ستون‌های قیمت دقیقاً مطابق دسترسی همان حساب از API برمی‌گردند.

## امنیت

- رمز عبور در فایل یا تنظیمات برنامه ذخیره نمی‌شود.
- نشست ورود در پارتیشن پایدار Electron نگهداری می‌شود.
- فایل `config/app.yaml` فقط تنظیمات غیرحساس را دارد.
- در صورت پایان نشست، برنامه دوباره صفحه ورود را نشان می‌دهد.

## قابلیت‌ها

- بروزرسانی خودکار طبق `refresh.interval_seconds`
- نمایش موجودی هر دستگاه
- نمایش همه ستون‌های قیمت مجاز حساب
- جست‌وجوی سریع بین دستگاه‌ها
- علامت افزایش و کاهش نسبت به آخرین بروزرسانی ذخیره‌شده
- اعلان ویندوز در صورت تغییر قیمت
- حالت همیشه‌روی‌صفحه طبق تنظیم YAML

## توسعه

```bash
cd desktop-price-widget
npm install
npm run check
npm start
```

## ساخت نصب‌کننده ویندوز

```bash
npm run pack:win
```

خروجی نصب‌کننده در پوشه `release/` با پسوند `.exe` ساخته می‌شود.\n\nپنجره در پایینِ سمت راست دسکتاپ باز می‌شود. دکمه تغییر اندازه آن را بین حالت کوچک و کامل جابه‌جا می‌کند. بستن پنجره، برنامه را در System Tray نگه می‌دارد؛ برای خروج کامل از منوی آیکون کنار ساعت ویندوز استفاده کنید.\n\nگزینه «اجرا همراه با ویندوز» فقط در نسخه نصب‌شده ویندوز فعال است. تنظیم انتخابی کاربر ذخیره می‌شود و اجرای بعدی آن را تغییر نمی‌دهد. فایل نصب ویندوز در CI ساخته می‌شود و باید قبل از انتشار عمومی از نظر امنیت و عملکرد آزمایش شود.

## نسخه عیب‌یابی

اگر نرم‌افزار موقع اجرا خطا بدهد، متن خطا و مسیر `desktop-errors.log` نمایش داده می‌شود. فایل لاگ در پوشه داده کاربر ویندوز نگهداری می‌شود؛ برای پشتیبانی فقط متن خطا را ارسال کنید، نه رمز عبور.

نسخه `Portable.exe` بدون نصب اجرا می‌شود؛ گزینه اجرای خودکار فقط برای نسخه نصب‌شده مناسب است. حداقل سیستم‌عامل Windows 10 نسخه ۶۴ بیتی است.
