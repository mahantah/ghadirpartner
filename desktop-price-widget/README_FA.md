# ویجت قیمت زنده قدیر پارتنر

این برنامه یک پنجره سبک ویندوزی برای نمایش قیمت و موجودی زنده دستگاه‌ها از پرتال قدیر پارتنر است.

## منبع داده

برنامه از API رسمی همان پرتال استفاده می‌کند:

- ورود: `/partners/api/login`
- احراز نشست: `/partners/api/me`
- قیمت و موجودی: `/partners/api/catalog`

هیچ صفحه‌ای اسکرپ نمی‌شود. ستون‌های قیمت دقیقاً مطابق دسترسی همان حساب از API برمی‌گردند.

## امنیت

- رمز عبور در فایل یا تنظیمات برنامه ذخیره نمی‌شود.
- نشست ورود در پارتیشن پایدار Electron نگهداری می‌شود.
- فایل `config/app.yaml` فقط تنظیمات غیرحساس را دارد.
- در صورت پایان نشست، برنامه دوباره صفحه ورود را نشان می‌دهد.

## قابلیت‌ها

- بروزرسانی خودکار طبق `refresh.interval_seconds`
- نمایش موجودی هر دستگاه
- نمایش همه ستون‌های قیمت مجاز حساب
- جست‌وجوی سریع بین دستگاه‌ها
- علامت افزایش و کاهش نسبت به آخرین بروزرسانی ذخیره‌شده
- اعلان ویندوز در صورت تغییر قیمت
- حالت همیشه‌روی‌صفحه طبق تنظیم YAML

## توسعه

```bash
cd desktop-price-widget
npm install
npm run check
npm start
```

## ساخت نصب‌کننده ویندوز

```bash
npm run pack:win
```

خروجی نصب‌کننده توسط electron-builder ساخته می‌شود.
