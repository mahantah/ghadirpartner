# قدیر پارتنر Android R6

این نسخه برای پرتال مشتری قدیر پارتنر ساخته شده و مستقیماً نسخه زنده زیر را باز می‌کند:

https://ghadirpartner.ir/partners/

## تغییرات R6
- بر پایه ساختار R5، اما با Wrapper جدید و پایدارتر.
- قفل دستگاه فقط یک بار در هر اجرای اپ تأیید می‌شود.
- پشتیبانی از Session و Cookie پرتال.
- پشتیبانی از انتخاب/آپلود فایل.
- پشتیبانی از دانلود فایل.
- لینک‌های تلفن، ایمیل و برنامه‌های خارجی خارج از WebView باز می‌شوند.
- خطای اینترنت صفحه سفید ایجاد نمی‌کند و صفحه Retry نمایش داده می‌شود.
- فقط دامنه ghadirpartner.ir داخل اپ باز می‌شود.
- نسخه زنده پرتال استفاده می‌شود؛ بنابراین تغییرات جدید سایت بدون Build دوباره داخل اپ دیده می‌شوند.

> اگر نسخه قدیمی با امضای متفاوت نصب باشد و Android اجازه Update ندهد، نسخه قدیمی را حذف و R6 را نصب کنید.
