# نصب نسخه PHP روی هاست لیموهاست

این نسخه برای هاست اشتراکی PHP/cPanel آماده شده و به Go، Docker یا VPS نیاز ندارد. اطلاعات در `storage/ghadir_data.json` نگهداری و با قفل فایل در برابر نوشتن هم‌زمان محافظت می‌شود.

## نصب

1. از اطلاعات فعلی هاست بک‌آپ بگیرید.
2. در cPanel وارد Domains شوید و `ghadirpartner.ir` را با Document Root مستقل بسازید؛ گزینه Share document root غیرفعال باشد.
3. فایل ZIP را در Document Root همین دامنه Upload و Extract کنید.
4. مطمئن شوید فایل‌های `index.php`، `app.html` و `.htaccess` مستقیماً در ریشه دامنه هستند، نه داخل یک پوشه اضافه.
5. دسترسی پوشه `storage` را روی 755 قرار دهید. اگر برنامه خطای نوشتن داد، 775 را امتحان کنید.
6. در MultiPHP Manager نسخه PHP 8.1 یا 8.2 را انتخاب کنید و افزونه‌های `json`, `session`, `mbstring`, `zip`, `simplexml` را فعال نگه دارید.
7. SSL رایگان دامنه را فعال کنید و Force HTTPS را روشن کنید.
8. دامنه را باز کنید. ورود اولیه: `admin` و رمز `123456`.
9. بلافاصله از داخل سامانه رمز admin را تغییر دهید.

## Data و ارتقا

- Data اصلی: `storage/ghadir_data.json`
- بک‌آپ‌ها: `storage/Backups/`
- پوشه storage توسط دو فایل `.htaccess` از دسترسی وب محافظت شده است.
- در ارتقا، پوشه storage را حذف یا جایگزین نکنید.
- برای انتقال Data ویندوز، فایل `ghadir_internal_data.json` را با نام `ghadir_data.json` داخل storage قرار دهید. رمزهای قبلی در اولین ورود به فرمت امن PHP تبدیل می‌شوند.

## تفاوت خروجی PDF

هاست اشتراکی مرورگر Headless ندارد؛ بنابراین دکمه PDF صفحه چاپ A4 را باز می‌کند. در پنجره چاپ می‌توانید Print یا Save as PDF را انتخاب کنید.

## مخزن

مخزن کارتن‌ها در این بسته مستقل و جدا از سفارش‌هاست. اطلاعات آن حفظ می‌شود و اتصال بعداً از `config.php` قابل فعال‌سازی خواهد بود.
